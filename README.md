# ANIVERSE Anime Search App
---

## Welcome
Welcome To **AniVerse**.

**AniVerse** is a web-based anime search application. And this is my project. This is the most ambitious Anime Search App project I’ve worked on and published so far. I’m still exploring and refining it, so naturally, the project isn't perfect yet.

I really hope this project keeps moving forward and continues to grow. To be honest, it started out just as a practice project for me.

Since this web app is deployed on GitHub, there are still some minor bugs. If a user navigates directly to a specific URL path or refreshes the browser while on an AniVerse sub-path, GitHub’s default "Page Not Found" screen appears. This happens because GitHub cannot locate a file that matches the requested URL path.

I won't be fixing this bug right away, as I have a life outside of coding, too. However, I do hope to address it as soon as possible.

This website still has limited information about anime, as it is essentially just a practice project of mine. I might continue developing it if I have some spare time, but I would appreciate any comments or suggestions you might have regarding the project.
